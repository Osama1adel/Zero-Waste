

**Zero Waste** is a comprehensive SaaS solution designed to revolutionize restaurant inventory and waste management. By integrating directly with POS systems like Foodics, it automates data synchronization, uses AI to predict and prevent waste, and provides actionable insights to managers.

## 🚀 Features (المميزات)

*   **📊 Centralized Dashboard**: Real-time overview of waste stats, potential loss, and branch performance.
*   **🔗 Automated Integration**: Seamless sync with Foodics for Sales and Inventory data.
*   **🤖 AI-Powered Insights**:
    *   **Waste Prediction**: Forecasts items likely to expire.
    *   **Smart Analysis**: Identifies root causes of waste (e.g., over-ordering, low sales).
*   **🏢 Multi-Branch Management**: specialized dashboards for Company Managers and Branch Managers.
*   **🔔 Smart Notifications**: Alerts for low stock, expiry warnings, and system updates.
*   **📝 Operational Requests**: Streamlined communication between branches and HEAD OFFICE.

## 🛠️ Technology Stack (التقنيات المستخدمة)

*   **Backend**: Django (Python)
*   **Database**: PostgreSQL
*   **Frontend**: HTML5, Bootstrap 5, Vanilla JS
*   **AI/Analytics**: Custom Python Logic & Pandas
*   **Integration**: Foodics API

## ⚙️ Installation & Setup

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Osama1adel/Zero-Waste.git
    cd Zero-Waste
    ```

2.  **Create Virtual Environment**:
    ```bash
    python -m venv venv
    ./venv/Scripts/activate  # Windows
    # source venv/bin/activate # Mac/Linux
    ```

3.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Run Migrations**:
    ```bash
    python manage.py migrate
    ```

5.  **Run Development Server**:
    ```bash
    python manage.py runserver
    ```
